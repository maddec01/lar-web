# Foundations

Lar's tokens live in `src/foundations/theme.css`. The palette is T3 Code's, on ninna-ui's scale, with Lar's navy as
primary. It applies under `html[data-theme='minimal']`, and `.light` or `.dark` on `<html>` picks one scheme (with
neither, it follows the system). Switch the toolbar theme to see every swatch below in both.

Components read these tokens through Tailwind utilities (`bg-base-100`, `text-primary`, `rounded-md`…). Apps never use
them directly.

## Type scale

Lar sets the platform UI font (`--font-sans`: SF Pro on Apple platforms, Segoe UI on Windows) at 14px, with
`--font-mono` for code. Apps pick a semantic `variant` on `Text` and `Heading`, never a size. The marketing variants
(`display`, `hero`, `headline`, `feature`, `lead`, `prose`) grow with the viewport.

## Icons

Every icon is from [lucide](https://lucide.dev/icons), under lucide's `…Icon` names, plus the brand marks lucide does
not draw (`GitHubIcon`). Apps import them from **`@lar-works/design-system/icons`**, never from `lucide-react`
(`lar/boundaries` reports that):

```tsx
import { Button } from '@lar-works/design-system';
import { PlusIcon } from '@lar-works/design-system/icons';

<Button leftIcon={<PlusIcon />}>Add library</Button>;
```

`DesignSystemProvider` draws them at a 1.75 stroke, which matches the weight of Lar's type, and components size them
(16px in buttons, 18px in header icon buttons). Inside the design system, components import icons from `lucide-react`.
