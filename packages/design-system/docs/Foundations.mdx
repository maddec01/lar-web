# Foundations

Every value here is drawn from the code: `src/foundations/tokens.ts` (documented role by role) and `theme.css`.
Components use the semantic tokens only, never a primitive, a `dark:` colour or a `color-mix()`
(`foundations/vocabulary.test.ts`); lengths, sizes, radii and tracking stay on the scales below (`scales.test.ts`).
