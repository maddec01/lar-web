# Lar's design system

`@lar-works/design-system` holds Lar's tokens, foundations and generic components, and names no product. Each app's
own compositions live in its UI layer (`src/ui`), built from this package's components, `/primitives` and tokens;
feature code outside `src/ui` only composes components and picks their semantic props (`@lar-works/config`'s lint
rules enforce it). A composition moves here, with a story, once a second product needs it. Installing:
[README](https://github.com/maddec01/lar-web/tree/main/packages/design-system#readme).

## Prop conventions

- **`variant`** is a look among equals; **`tone`** is a status colour (`neutral`, `info`, `success`, `warning`,
  `danger`, plus `accent`), never a look and never `error`; **`size`** is one ladder, `xs`–`xl`, never a boolean
  such as `compact`; **`density`** is how tightly rows pack; **`presentation`** is only a structurally different
  layout of the same content.
- Labels are props: components hold no copy, routing or i18n. Public components take no `className`; compositions
  use the `…Base` export from `/primitives`.

## Cross-app rules

- **The status-word rule.** A state (Merged, Failed, Running) is a `StatusIndicator`: its light, then its word in
  neutral text. A tone `Badge` is only for a verdict or a category ("Worth fixing", "Beta"). A state is never a tinted
  pill or a word in a tone's colour.
- **The button-variant rule.** `primary` is the one commit per view (never two, never on a row); `tinted` acts on an
  item (Start, Review, Resume) in every row, card and popover; `secondary` is every other action (Try again, Cancel,
  an empty state's or Alert's action, and any action under a paragraph, so its edge lines up with the text); `quiet` is
  a low-stakes action inside a row.
- **The quiet-destructive rule.** A control that starts a destructive action is in the danger text colour at rest,
  quiet, and gains the danger surface on hover or focus (`Button variant="destructive-quiet"`,
  `IconButton tone="danger"`, `DropdownMenu.Item destructive`), never neutral grey. It opens a `ConfirmDialog`, whose
  confirm button is the only solid red control. The only sentence in danger text is a field's error.
- **Notices.** Every notice is an `Alert`, message first, never a box of an app's own; never bare red text under a
  row. Toasts are only for results whose surface is gone.
- **Unsaved changes.** A dirty `Modal` asks before closing; a control that leaves it calls `useModalClose()`, never a
  discard dialog of the app's own.
